운동은 칼로리 예산에 더하지 않아요. 소모량 추정치는 실제보다 부풀려지는 경우가 많고, 활동량은 이미 목표 계산에 반영돼 있어서 이중으로 세면 적자가 사라집니다.

본인의 Anthropic API 키를 넣으면 "직접 입력" 탭에서 사진으로 영양성분을 채울 수 있어요. 키는 이 기기에만 저장되고 앱 밖으로 나가지 않습니다. platform.claude.com 에서 발급받을 수 있어요.

영양성분표는 표에 적힌 숫자를 읽는 거라 Haiku로도 충분하고, 음식 사진 추정은 Sonnet이 더 정확해요. 어느 쪽이든 결과는 폼에 채워지기만 하고, 확인하고 "추가하기"를 눌러야 기록됩니다.

식이섬유 기능이 생기기 전에 적은 기록에는 섬유 값이 없어요. 음식 목록과 대조해서 자동으로 채워넣습니다. 목록에 없는 음식(직접 입력한 것 등)은 그대로 비어 있고, 오늘 기록 화면에서 ✎ 버튼으로 직접 고칠 수 있어요.

하루 목표 칼로리를 끼니별로 나눠요. "끼니별 칼로리 분포" 카드에 목표 대비로 표시됩니다.

전체 기록(끼니, 체중, 목표치, 즐겨찾기)을 텍스트로 내보내거나, 백업해둔 텍스트를 붙여넣어 복원할 수 있어요.
